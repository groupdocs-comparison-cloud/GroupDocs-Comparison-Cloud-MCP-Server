# GroupDocs.Comparison Cloud MCP Server

MCP server for GroupDocs.Comparison Cloud with product tools and shared cloud storage tools.

## Core product tools

- `comparison_supported_formats`
- `comparison_get_info` / `comparison_extract` / `comparison_search` / `comparison_split` / `comparison_compare` / `comparison_assemble` (as applicable)

## Shared storage tools

- `file_upload`, `file_upload_local`
- `file_download`, `file_download_local`
- `folder_list`, `file_exists`, `folder_exists`
- `file_delete`, `folder_delete`

## Environment

```
CLIENT_ID=your-client-id
CLIENT_SECRET=your-client-secret
MCP_PORT=8000
```

Server endpoint: `http://127.0.0.1:8000/mcp`
